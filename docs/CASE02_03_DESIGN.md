# 案件 02 / 03：实现规格

日期：2026-10-14。状态：已按以下规格编码并通过构建，交互验收单独记录。

## 案件 02：读出星系的运动

1. 调节旋转速度 80–260 km/s 与倾角 15–85°，比较虚线模型和实线教学谱线。
2. 谱形匹配指标达到 96% 后记录第一组模型，保存投影歧义证据。
3. 申请光学轮廓：在薄圆盘假设下，b/a≈0.71，对应 i≈45°。
4. 同时满足倾角约束（45±2°）、旋转速度约束（180±10 km/s）及谱形匹配，再保存模型。
5. 选择“运动与观察角度共同决定谱形”，形成结案卡。

谱线由薄圆盘圆环叠加，径向密度与旋转曲线形状固定，速度弥散 σ=12 km/s。横轴为相对系统速度，纵轴为峰值归一化强度。匹配指标只服务教学，不是拟合置信度；光学轮廓不是真实目标测量。

错误解释分别反馈倾角的作用，以及由谱线高度直接估计质量所缺少的标定和距离。

## 案件 03：气体去了哪里

1. 在同一视场切换光学、HI 和相对视向速度图。
2. 在 HI 图选候选桥区域 A，保存形态证据。
3. 在速度图选同一区域，保存沿桥连续变化的运动线索。
4. 三种视图都查看过、两类证据都保存后，选择支持相互作用但保留不确定性的解释。
5. 形成第三张结案卡，并进入三案总收尾与个人档案夹。

光学图包括两个独立星光盘；HI 教学场人为设置盘间桥状结构。沿桥相对速度在 +115 至 +90 km/s 平滑变化，不来自流体动力学模拟。颜色表示视向速度，不是温度。

这些线索支持继续检验星系关联 / 相互作用，不声称唯一证明潮汐气体转移或确定三维位置。专业审核仍需用户完成。
