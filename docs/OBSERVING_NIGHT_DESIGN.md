# 观测夜 01：黎明前的回波

日期：2026-10-14。用户认为工具交互可以，但希望增加故事性，并授权由 Codex 决定射电望远镜观测环节的细节。

## 故事与玩家动机

山脊射电阵列的最后一个时段，上一班在虚构目标 GX-07 盘外发现一条弱线，却没有足够证据判断它是否属于目标。玩家作为接班观测者，在 28 个模拟分钟内安排校准、参考场诊断与目标观测。值班员林岚通过工作便笺与反馈陪同。目标是留下有证据的交班记录，说明发现了什么、仍不能确定什么，而非猜某种唯一演化机制。

## 完整操作循环

1. 阅读交班便笺，决定先了解全盘运动，还是优先追查弱线。
2. 在寻源图或偏置滑块调整阵列指向，检查主波束响应。
3. 调谐中心频率与总带宽；通道分辨率固定，带宽决定覆盖。
4. 观测虚构校准源（2 分钟），完成简化标量增益校准。
5. 观测参考场诊断谱（2 分钟），检查在人为设置的干扰频率是否有相同窄线，决定是否标记坏通道。
6. 分配 4 / 8 / 16 分钟给目标，观看压缩时间的观测进度。
7. 获得由这些选择改变的真实 Float32 cube，在现有工作台自由探索并记录。
8. 比较两处有效运动信号并记录弱候选，提交谨慎的交班结论；不足时可保留现状，调整方案或开始下一夜。

自由工作台始终可直接进入。旧存档与已有模拟对象保留。

## 物理约定与教学简化

- 目标与阵列均为虚构；源模型仍用已经验证的扰动 PPV 模拟，不冒充 M33。
- 频率在模型系统静止参考系示范；使用射电定义 ν=ν₀(1−v/c)，ν₀=1420.40575 MHz。不宣称经过真实地心 / 日心参考系修正。
- 阵列主波束采用 FWHM 14 arcmin 的 Gaussian，对无噪声源逐像素衰减。合成波束仍为原模型 16 arcsec，两者不得混淆。图像不做主波束校正。
- 最新指向修正：新观测以当前指向为成像中心，8.5′ 输出画幅随指向移动，源双线性重采样；光学 / HI / FITS 坐标一致。14′ 主波束不是 8.5′ 画幅的硬边界，源图外为空天空是模型假设。历史批次保持版本 1 固定目标画幅，不静默重写。
- 通道图按用户要求逐通道 signed min–max 线性映射到 inferno，动态数值色标；纯噪声可铺满色阶，缺测灰色显示。固定线性比较可选；积分图 / PV / 谱的强度比例独立。最新实际验证见 [POINTING_AND_CHANNEL_QA.md](POINTING_AND_CHANNEL_QA.md)。
- 固定通道宽度 5 km/s，噪声按 σ∝t⁻¹ᐟ² 缩放，16 分钟对应原模型噪声。带宽不改变单通道噪声；不借此虚构带宽—谱分辨率权衡。
- 使用无噪声 cube 与原噪声残差，共同生成观测结果；不同批次平移残差，保留相关结构，非完整独立随机噪声模拟。
- 未覆盖 / 被标记的通道保留 NaN，不能填零装作测量。RFI 注入为固定窄谱的现象学污染，不是完整干涉仪电磁响应。
- 校准仅演示一个相对增益系数，未计算可见度、uv 覆盖、相位、成像反卷积与真实观测调度。操作时长为游戏内模拟分钟。
- S/N 仍是探索指标；交班中不把一张 moment 图或一条弱线直接当作潮汐形成的证据。

科学依据：[NRAO 辐射计与望远镜](https://www.cv.nrao.edu/~sransom/web/Ch3.html)、[VLA 校准说明](https://science.nrao.edu/facilities/vla/docs/manuals/obsguide/calibration)、[NRAO RFI 说明](https://science.nrao.edu/facilities/vlba/docs/manuals/obsvlba/rfi)。上述资料支持原则，游戏参数与剧情均为本项目设计。
