## 使用方法

1. 从 [AGENTS.md](../../AGENTS.md) 开始，阅读最新记录，再按需要追溯历史。
2. 每个有独立结果的步骤完成后，复制 [模板](TEMPLATE.md)，填写实际完成情况。
3. 文件命名采用 `YYYY-MM-DD-NNN-short-slug.md`，当日序号递增，避免覆盖已有记录。
4. 更新本文件的最新记录链接、状态摘要、下一步和记录列表。
5. 明确区分已完成、进行中、建议和待确认；验证未执行时写明原因。
