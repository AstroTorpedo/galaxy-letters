# 指向成像与逐通道线性显示验收

日期：2026-10-14。用户指出指向看不出影响，并要求每个 channel 线性拉伸、色标跟随本通道数值范围。

本记录对应 handoff 015 / 016。当时使用的共用谱纵轴随后按截图反馈改为独立自动适配与缩放，最新行为见[谱显示 QA](SPECTRUM_DISPLAY_QA.md)；本记录的物理数据与通道显示验证保留。

## 发现与修正

旧模型在固定目标画幅中施加主波束衰减，并自动缩放每批图像 / 谱纵轴。衰减有进入数据，但目标始终居中、对比尺也变化，玩家容易认为指向不起作用。

新观测将指向与成像中心同设为当前视场中心：源重采样到移动的 8.5′ 画幅，主波束与源相对方位一致，源图外采用空天空模型并保留接收噪声。光学示意、参考轮廓、盘外判定、角偏置与 FITS WCS 同步移动。

8.5′ 是本原型的输出成像画幅，14′ 是主波束 FWHM，不把前者当作望远镜主波束硬边界。真实成像软件可指定独立的成像中心；本项目采用同向设置。原理参考 [NRAO 主波束说明](https://science.nrao.edu/facilities/vla/docs/manuals/oss2013A/performance/fov/pbeam)、[CASA 成像说明](https://casaguides.nrao.edu/index.php?title=VLA_CASA_Imaging-CASA6.2.0)。具体参数和空天空假设是教学模型。

## 通道显示约定

- 默认逐通道线性 min–max：读取当前 plane 的所有有限像素，保留负噪声，直接线性映射到 inferno。
- 每次换通道重新计算并更新色标两端与 mJy/beam 单位。
- 不使用阈值压暗原始通道像素，也不对通道图施加 asinh。积分图的拉伸与掩膜独立。
- 纯噪声同样可占满色阶，因此也可能很亮；读实际色标幅度、谱线和连续性，不能把亮色等同于检出。
- 缺测 / 被标记的 NaN 通道灰色显示，色标明确写“缺测”，不填零、不虚构数值范围。
- 可切换固定线性范围用于同源绝对强度对照。积分图 / PV / 谱默认共用源参考强度尺，保留自动增强选项。
- 图鉴的批次封面也由各自观测 cube 生成，不再统一显示源模型封面。
