# 孔径谱自动纵轴与交互缩放

日期：2026-10-14。用户截图指出共用 9.11 mJy/beam 纵轴留白过多，弱谱波形不清楚，要求动态纵轴或交互缩放。

## 已实现

- 孔径谱默认自动贴合当前有限数据，包含负噪声、3σ 范围与少量边缘；移动选区或改变孔径后重新适配。
- 独立的谱纵轴模式：自动贴合 / 同源共用。与通道 min–max、积分图 / PV 强度标尺分别控制。
- “纵轴放大 / 缩小”按 1.5 倍调节，范围 ×0.25…×16；“适配当前谱”一键回到自动范围和 ×1。
- 坐标数值始终为实际 mJy/beam；改变纵轴不改变谱数组、峰值、S/N、速度或发现条件。
- 放大导致曲线超出范围时，只在绘图区内裁切，并给出提示，不让曲线覆盖轴标签。
- 移除谱 SVG 的高度上限造成的额外留白，按卡片宽度使用完整图幅。
