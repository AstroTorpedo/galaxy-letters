## 浏览器完整流程

1. 打开 `/explore.html?night=1`，显示交班便笺和两种观测优先选择；进入控制台，观测前要求校准。
2. 测试不理想配置：E +7′、N −5′（目标中心主波束响应约 35%）、0.8 MHz、4 分钟、未查参考场 / 未标记 RFI。校准后预算 26 分钟，短观测后剩 22 分钟；只覆盖 34/101 个通道，谱中仍有干扰。不能直接提交有证据的结论。
3. “证据不足”交班分支可提交，并提示保留数据、补充观测。
4. 点击寻源图可修改指向；对准目标、回到系统中心、2.8 MHz；参考场显示 +35 km/s 同频窄峰，检查消耗 2 分钟。勾选坏通道标记，分配 16 分钟。
5. 长观测后得到 98/101 个有效通道；+30、+35、+40 km/s 为 NaN，剩余预算 4 分钟。两批可在对象栏来回比较。
6. 在自由工作台记录两侧谱，中心速度约 +69.8 / −67.6 km/s，S/N 约 29.3 / 40.1；记录盘外位置约 (37, 48)，初始半径 2 像素只有 2 个连续越阈通道。
7. 将该孔径扩大到 3 像素，得到 S/N 约 6.9、中心速度 −55.8 km/s、连续 3 通道，满足弱候选条件。盘外条件由星光模型参考轮廓计算，不是固定热点。
8. 提交有证据的交班：记录运动与弱候选、已标记的参考场干扰，同时明确不足以断言潮汐成因。
9. 刷新后最近批次、观测参数与发现证据仍可使用。安排下一夜后预算恢复 28 分钟且重新要求校准；历史交班在换夜和刷新后保留。
10. 本次 FITS 下载使用当前观测数组，包含指向、频段、曝光、RFI 标记、批次、主波束约定与角偏置 / VRAD WCS。独立 Python 模型与文件完全一致。
11. 选择 +35 km/s 通道显示“缺测”，谱线灰带断开，不跨坏通道连接。最后页面错误日志为空。

测试记录只保存在 4174。用户 4175 的观测夜不注入通关、发现或交班记录。

## 具体限制

这是已有成像源模型上的观测教学层：没有计算真实可见度、uv 采样、相位或 CLEAN。校准仅演示标量增益；RFI 为人为注入的窄谱污染。噪声用相关残差平移与缩放，不是独立的真实观测重复。频率在模型系统静止系演示，不表示真实天体的地心 / 日心频率。主波束未校正。

剧情暂为一段完整观测夜；角色立绘、多个独立故事、望远镜运动控制与更完整观测策略仍可据试玩反馈扩展。未验证手机 / 全部浏览器；未打包、未上传。
