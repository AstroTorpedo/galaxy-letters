21厘米：星系来信 / Galaxy Letters
教学试玩版 v0.1.0

三个案件：看见气体 → 读出星系运动 → 追踪气体去向。

Windows：解压完整文件夹后运行 GalaxyLetters.exe，保留同目录的其他文件。
macOS Apple Silicon：打开 GalaxyLetters.app。本包不支持 Intel Mac。
玩家无需安装 Node.js 或 Python。图片、数据、字体与代码均在本地，核心游戏无需联网。

点击切换观测方式；在图中或下方按钮选择区域；把线索加入证据夹，选择解释并提交。
第二案可用滑块或键盘方向键调节模型。手册提供单位、假设与科学背景。
进度自动保存在本机；“我的档案”可导出、导入进度，或保留备份重新探索。

全部星系图、谱线与速度场为程序生成的教学模拟，不是真实观测。
场景背景使用 AI 生成概念图；科学图与交互 UI 由代码绘制。
本版尚待专业科学审核与外部用户试玩，不应据此声称已证明教学有效。

平台验证状态请以随版本发布的说明为准。macOS 本地构建使用 ad-hoc 签名，尚无 Developer ID 公证；Windows 包尚无发行者签名。
本包是供审阅的试玩版本，公开发行前还需完成目标平台分发与签名流程。
