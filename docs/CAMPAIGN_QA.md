## 完整流程观察

1. 新游戏显示林岚立绘、两份申请与交接入口。对话可以问上一班发生的事、两个目标的目的，也可选择新手引导。
2. 教程按实际操作变化：主波束中心 → 频段 → 校准 → 参考场 / 标记 → 观测。点击“带我去这里”可以定位当前控件，不自动替玩家完成证据。
3. 归航使用 sim-disk，8 分钟积分。查看速度场并保存两侧谱，中心速度约 +76.7 / −83.0 km/s，S/N 约 44.8 / 21.9。仅归航任务完成，回波仍待调查。
4. 林岚出现“现在，我们有一份可靠的对照了”阶段回应，可从对话接受回波调查。两目标均可直接选择，不是锁住的线性关卡。
5. 回波使用 sim-disturbed，16 分钟积分；同夜校准 / 参考场沿用，本轮 2+2+8+16=28 个模拟分钟。
6. 对照光学、HI 和通道，保存盘内参照。盘外测试位置扩大到半径 3 后，S/N 约 6.9，峰约 0.58 mJy/beam，中心 −55.8 km/s，连续 3 通道。保存后任务 2 完成。
7. 两份任务汇入同一结局，林岚接收双目标报告；报告保留独立复观测、形成机制未定的科学边界。提交后可继续自由看数据，不重复添加最终报告。
8. 引导可关闭 / 再开启，方法与对话可重看；刷新后任务、批次、发现与报告保留。
